# 소개

두레시장은 여러 mycart 스토어를 탐색하고 쇼핑할 수 있는 크로스 플랫폼 mycart 브라우저입니다. 듀얼 모드 브라우징(웹뷰 및 API)과 통합 장바구니 관리 기능을 제공합니다.

## 주요 기능

### 듀얼 모드 브라우징

두 가지 모드로 mycart 스토어를 탐색할 수 있습니다:
- **웹뷰 모드**: 임베디드 브라우저를 통한 완전한 웹사이트 렌더링 (데스크톱 및 안드로이드)
- **API 모드**: 최적화된 성능을 위해 mycart REST API를 직접 호출하는 네이티브 UI

### 스토어 디렉토리

[dure.one](https://dure.one) 디렉토리에서 여러 mycart 스토어를 동기화하고 탐색합니다. 다양한 스토어를 쉽게 발견하고 탐색할 수 있습니다.

### 장바구니 관리

- 실시간 업데이트를 지원하는 인앱 장바구니 관리
- 이미지 미리보기가 포함된 제품 탐색
- API 모드에서 장바구니 추가 기능
- 세션 간 장바구니 지속성

### 탭 관리

- 지속적인 탭을 지원하는 멀티탭 브라우징
- 즐겨찾는 스토어에 빠르게 접근할 수 있는 북마크
- 탐색 기록 추적
- 세션 복원

### 크로스 플랫폼 지원

- **데스크톱**: GTK/WebView2/WebKit을 사용하는 Linux, macOS, Windows
- **안드로이드**: Android WebView 통합을 지원하는 네이티브 APK

## 기술 스택

Dure-Sijang는 다음 기술로 제작되었습니다:
- **Rust**: 핵심 애플리케이션 로직
- **egui**: 크로스 플랫폼 UI 프레임워크
- **wry**: 크로스 플랫폼 웹뷰 라이브러리
- **Diesel + SQLite**: 로컬 데이터 지속성
- **smol**: 백그라운드 작업을 위한 비동기 런타임
